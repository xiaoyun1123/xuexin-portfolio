# 心迹 · 可点击高保真原型 v0.1

## 打开方式

双击 `index.html`，用 Chrome / Edge / Safari 打开即可。无外部依赖、无需启动服务。

- 桌面建议视口：1280 × 800 以上
- 手机也可直接打开，会隐藏左侧说明、只保留手机

## 可以点的地方

| 页面 | 可交互 |
|---|---|
| 引导 | 开始 / 先随便看看 → 今天 |
| 今天 | 点任意天气即完成一次记录；换一个推荐；查看本周洞察；我现在很难受 |
| 记录 | 选情绪、强度、标签；语音按钮（模拟转写）；保存 → 反思卡 |
| 洞察 | 周 / 月切换；「这是怎么算的」完整口径；加入实验；情绪账本；情绪日历 |
| 疗愈 | 按状态 / 时长筛选；4-7-8 呼吸计时；音频播放器（可暂停）；书写练习 |
| 我的 | 应用锁 / 本地模式 / 云端分析开关；安全计划；导出；会员 |
| 情绪急救 | 12356；紧急联系人；60 秒着陆；安全计划展开 |

隐藏玩法：手机里的「记录」是底部中间的 +；洞察要往下滑才能看到账本和日历；呼吸页有真实的 4-7-8 计时与结束复评。

## 设计方向

**情绪气象台 × 纸质手账。**

- 暖纸色（#F3EDE1）+ 墨（#211E19）+ 陶土红（#B45B3C），不用常见的疗愈紫/蓝渐变。
- 标题用 Noto Serif SC（宋体骨架），数据用等宽字体，正文用 Noto Sans SC。
- 天气符号替代 emoji 脸，既降低“被评判”的感觉，也形成产品记忆点。
- 信息密度克制：一屏只回答一个问题。

## 覆盖的核心闭环

```
点天气（3 秒）→ 一句接住 + 一个动作 → 洞察（证据卡）→ 情绪实验 → 复评 → 个性化
```

四个关键设计决策在原型里的落点：

1. **3 秒记录**：首页天气行，点完即存，不强制写文字。
2. **可解释洞察**：触发因素卡展示样本、反例、效应量、置信区间，并提供「这是怎么算的」。
3. **闭环推荐**：呼吸 / 音频 / 书写都有开始与结束，结束时有「好一点了吗」。
4. **安全网**：首页常驻急救入口；急救页不锁死用户，提供 12356、联系人、着陆练习与安全计划。

## 已知限制

- 演示数据，不是真实账号体系；刷新即重置。
- 语音输入是模拟（1.9 秒后填入示例文本），未接 ASR。
- 音频播放器是计时示意，没有真实音轨。
- AI 反思是模板文案，未接模型；「这是怎么算的」中的数字是静态示例。
- 月视图、社区、咨询转介、订阅支付未实现。
- 危机流程是交互示意，不构成真实干预。

## 下一步（建议顺序）

1. 用这份原型做 8–12 人可用性测试，重点验证「3 秒记录是否真的 3 秒」和「证据卡是否看得懂」。
2. 通过后进入 MVP 技术脚手架：Flutter + 本地库 + 记录/洞察两条主链路。
3. 同步准备合规材料：隐私政策、单独同意、危机 SOP、算法备案清单。
