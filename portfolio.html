A 股智能选股与量化风控系统 ↗
5,500+ 全市场筛选

基于多 Agent 协作的 A 股智能分析系统，从全市场 5,500+ 只股票中通过三级漏斗筛选精选标的，综合技术面、基本面、情绪面与 LLM 决策。

  • 三级漏斗架构：0 级纯规则 15 秒筛除 99% 无效标的 → 1 级 LLM 主题判断 → 2 级四 Agent 并行深挖（技术/基本面/情绪/决策）
  • 四维度多因子加权评分（技术 30% + 基本面 25% + 情绪 25% + 板块对齐 20%），每只标的输出 0-100 评分 + BUY/SELL/HOLD + 目标价位 + 风险等级
  • 多层风控体系：日亏损 3% 熔断 + 单只 20% 仓位上限 + 总数 5 只 + T+1 规则 + LLM 熔断器（3 次连续失败→断开 60s→试探→恢复）
  • 6+ 数据源三源容灾：每个数据点配备主/备/兜底三个来源，东财 API 封禁→腾讯财经 HTTP 直连→新浪 K 线替代

MCP Server 矩阵（4 个）↗
166+ 工具接口

从零开发 4 个 MCP（Model Context Protocol）Server，将不同系统的数据能力封装为标准化 API 供 AI Agent 调用。

  • Zotero MCP：基于 SQLite 的文献数据库查询服务，90+ 篇论文元数据结构化查询，支持复杂 SQL 分析与 schema 探查
  • Obsidian MCP：知识库文件系统服务（7 个工具），全文搜索、双向链接分析、断链检测
  • Stata MCP：统计计算服务，subprocess 调用 StataMP 执行批处理计量分析（DID/固定效应/Fama-MacBeth），含破坏性操作自动检测
  • blend-ai MCP：Blender 3D 建模服务，双向 TCP 架构（Python ↔ Blender Addon），覆盖建模/材质/动画/物理仿真/渲染全流程
